# Design: Playbook Testograf для клиентских опросов

Дата: 2026-11-03  
Статус: утвержден (подход B + процесс запуска от заказчика)

## Цель

Операционный playbook для сотрудников, которые собирают клиентские опросы в Testograf (тариф PRO+): какие настройки включать/выключать, зачем они нужны, как избегать нерепрезентативных ответов, как чистить данные после сбора.

## Scope

Входит:
- NPS, CSI, CSAT, голосования, послесервисные опросы
- Настройки Testograf до запуска
- Корпоративный процесс согласования и запуска
- Правила постобработки ответов

Не входит:
- HR (360, вовлеченность, тесты знаний) — отдельный документ при необходимости
- Формальный приказ/регламент с юридической силой

## Подход

Карточки настроек (зачем / где в UI / когда вкл / когда выкл / риски) + сводная матрица по типам опросов + постобработка + чеклист. В начале — обязательный процесс «как мы работаем с опросами».
