# Каталог Testograf: типы вопросов и настройки

Источник фактов: официальные страницы Testograf ([Функционал](https://www.testograf.ru/ru/functions), [Помощь](https://www.testograf.ru/ru/help), [Мануал](https://www.testograf.ru/ru/blog/manual), статьи блога Testograf по ссылкам в разделах).  
Тариф компании: **PRO+**.  
В тексте нет домыслов: где в открытой справке нет детального описания — так и сказано.

Колонка **«Наши типы опросов»** (NPS / CSI / CSAT / голосование / послесервис) заполняется так:
- если Testograf **прямо** связывает тип с NPS, CSI или голосованием — указано;
- если Testograf относит тип к UX / продукту / тестам знаний — указано назначение Testograf; для клиентских NPS/CSI/CSAT/послесервис — **только по брифу**, не как «базовый» тип метрики;
- CSAT как отдельный тип вопроса в Функционале **не назван**; для оценки касания в Testograf используются шкалы / выбор / открытые вопросы по смыслу брифа.

---

## 0. Наш процесс запуска (корпоративный)

1. Бриф от заказчика (или готовим сами).  
2. Заводим опрос в Testograf.  
3. **Отключаем** ограничение повторного прохождения (чтобы тестировать).  
4. Внутренняя проверка логики и ошибок.  
5. Проверка заказчиком.  
6. Параллельно — коммуникация.  
7. Согласование опроса и коммуникации: **Голубева Екатерина Анатольевна**.  
8. Зачистка тестовых ответов → **включаем** ограничение повторного прохождения.  
9. Запуск.

## 1. Типы вопросов (как в Функционале + детализация в Помощи/блоге)

Базовые настройки **любого** вопроса (мануал): подсказка (текст / изображение / видео / ссылка); обязательный или необязательный; таймер к вопросу; случайный порядок вариантов ответа; комментарий к ответу (обязательный или нет).

## 2. Логика

### 2.1. Обычная логика (вкладка «Логика», мануал)

- По умолчанию — прямая логика: любой ответ → следующий вопрос.  
- Можно направить на: страницу, вопрос, стандартное / индивидуальное завершение, **дисквалификацию**.  
- **Выбор одного:** условие «выбрал / не выбрал / всегда»; в одном условии можно отметить несколько вариантов.  
- **Выбор нескольких:** «выбрал указанные / не выбрал / всегда»; связки **И/ИЛИ — в продвинутой логике (PRO+)**.  
- **Свободный ответ, ранжирование и т.п.:** только переход «всегда» (нельзя ветвить по тексту ответа в обычной логике).  
- **Матрицы:** условие по **ячейкам**.  
- Перед запуском Testograf рекомендует протестировать все ветвления.

**Выход:** респондент идет по своему маршруту; дисквалифицированные видят страницу дисквалификации и не смешиваются с целевым сценарием так, как задано условиями.

**Наши опросы:** скринер ЦА, «пользовался услугой → уточнения», ветки послесервиса — типовое применение обычной логики.

### 2.2. Продвинутая логика (PRO+, Помощь)

- Условие + действие; условия из **ответов на разные вопросы** и **параметров ссылки**; операторы **И / ИЛИ**.  
- Параметр ссылки: «содержит / не содержит».  
- Один вопрос/параметр — не чаще одного раза в одном наборе условий.  
- Действия: переход к вопросу/странице; показ или пропуск списка вопросов/страниц; завершение (стандарт / индивидуальное / дисквалификация), сразу или после определенного вопроса.  
Примеры в справке: фильтр ЦА, дисквал нерелевантных, индивидуальное завершение для высоких оценок.

### 2.3. Piping и конвейер (Помощь)

- **Piping:** подстановка ответа/параметра ссылки в тексты вопросов, вариантов, приветствие, завершение.  
- **Конвейер:** выбранные варианты становятся вариантами/строками следующего вопроса (матрицы, ранжирование, CSI и др. — см. списки отправителей/получателей в Помощи).

## 4. Сводка: что брать в какой наш опрос

Только пересечение **типа из Testograf** и **нашего названия опроса**:

| Наш опрос | Типы вопросов из каталога Testograf, которые прямо соответствуют цели | Настройки, которые Testograf + наш процесс требуют особенно |
| --- | --- | --- |
| **NPS** | Тип **NPS**; плюс выбор одного/нескольких, открытый текст, матрицы/Лайкерт для доп. блоков | Повтор устройства вкл на бою / выкл на тесте; незавершенные — для длинных; SMS обычно выкл (барьер для лояльности); рандом шкалы NPS выкл |
| **CSI** | Тип **CSI**; матрицы/Лайкерт по параметрам; выбор нескольких для важности параметров (как в статье CSI) | То же по повторам; длина 3–5 параметров для b2c (рекомендация Testograf) |
| **CSAT** | Отдельного типа «CSAT» нет: звезды/смайлы/Лайкерт/выбор + текст | Короткие формы; персональные ссылки/параметры ID при известном касании |
| **Голосование** | Выбор одного / изображения; парное сравнение; при накрутках — SMS-подтверждение | Повторы + SMS/перс. ссылки; показ итогов во время сбора — осторожно |
| **Послесервис** | Шкалы + выбор + текст; контакты/параметр ID обращения | Идентификация респондента/обращения; логика «обращался / нет» |

UX-типы (first click, Figma, 5 сек, A/B, card sort, восприятие текста, MaxDiff, Conjoint, Кано) — по Testograf для **продукта/UX/маркетинга макетов**; в регулярный NPS/CSI жителей **не входят**, пока бриф явно не ставит такую задачу.
